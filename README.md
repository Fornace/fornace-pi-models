# fornace-pi-models (absorbed)

This package is absorbed by [pi-mantice](https://github.com/Fornace/pi-mantice):
live Mantice catalog sync for Pi, now with capability fields (mode/class/
modalities/thinking), class metadata, flash-class compaction, canonical
overflow recovery, and gateway onboarding.

Switch with:

    pi remove ../../works/repos/fornace-pi-models   # or drop the settings entry
    pi install git:github.com/Fornace/pi-mantice@v1.0.0

The catalog translation lineage lives on in pi-mantice `src/catalog.ts`
(includes the fail-closed >128K guard added after the 2026-09-03 metadata
incident). This repo stays for history.
